Welcome to Sparx Solver

A browser extension that helps automate Sparx Maths and Sparx Science tasks directly inside Chromium.

How the extension works

Sparx Solver runs as a Chrome extension inside this browser. After you open your Sparx Maths or Sparx Science homework, the extension can read the current question, collect the required information, and run the automation process from the browser itself. Your login session stays inside this Chromium profile, so you do not need to log in every time.

⚠️ Important: Chromium Account Notice

If Chromium asks you to "Sign in to Chromium", do not sign in. Choose "Use Chromium without an account" instead. This keeps the Chromium profile separate and avoids connecting it to a personal Google account.

First-time setup

1

Enable Developer Mode

Open chrome://extensions in a new Chromium tab (copy and paste the address into the top bar). Turn on the Developer mode switch in the top-right corner. This allows Chromium to load the Sparx Solver extension.

2

Login to Sparx Maths or Sparx Science

Open Sparx Maths or Sparx Science and sign in using your school account. Your login session will be saved so you do not have to repeat this every time.

3

Open your homework

Go to the homework section and open the task you want to work on. Make sure you are on a page containing a question.

4

Open Sparx Solver

Click the Sparx Solver extension icon at the top of Chromium. It should appear using the Sparx Solver logo.

5

Start the assistant

Use the extension panel to start automation. The assistant will then run while keeping the browser open.
